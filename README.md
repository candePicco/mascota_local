# 🐾 Mascotas App

## 📌 Descripción del proyecto

Mascotas App es una aplicación web desarrollada con Next.js que permite visualizar mascotas en adopción, acceder a casos urgentes y ver detalles individuales de cada mascota.

## 🚀 Funcionalidades

* Página de inicio
* Listado de mascotas en adopción
* Sección de mascotas urgentes (ruta anidada)
* Vista de detalle por mascota (ruta dinámica)
* Página para reportar mascotas

## 🧭 Rutas

* `/` → Inicio
* `/adopciones` → Listado de mascotas
* `/adopciones/urgentes` → Mascotas urgentes
* `/mascota/[id]` → Detalle dinámico
* `/reportar` → Reportar mascota

## 🛠 Tecnologías utilizadas

* Next.js
* React
* Tailwind CSS
* JavaScript

## ▶️ Cómo ejecutar el proyecto

1. Clonar el repositorio:

```bash
git clone URL_DEL_REPO
```

2. Instalar dependencias:

```bash
npm install
```

3. Ejecutar el proyecto:

```bash
npm run dev
```

4. Abrir en el navegador:

```
http://localhost:3000
```
